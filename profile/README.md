## nexovue

Observability that tells you what broke and why, not fifty dashboards to read.

Traces, metrics, logs, errors, uptime checks and real user monitoring in one place, built on
OpenTelemetry, so your applications send to nexovue with the SDKs they already use.

**Run it on your own server**

```bash
curl -fsSLO https://github.com/nexovue-tech/nexovue/releases/latest/download/install.sh
sudo bash install.sh
```

One Linux server with Docker and 16 GB of memory. Upgrades, rollbacks and backups are one command each.

- [@nexovue/browser-sdk](https://www.npmjs.com/package/@nexovue/browser-sdk): real user monitoring for websites
